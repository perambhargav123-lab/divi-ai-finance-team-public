Start here

Divi is an AI finance team for a small UAE business. It closes the month's books, has an independent auditor check them, and finds cash the owner can use.

  1. Click Run the close (top right) and watch five agents read receipts, match the bank and post the books. It takes about a minute.
  2. See what they caught: a hidden AED 18,500 sale and a AED 50,000 payment to a brand new vendor that you can block.
  3. See the auditor sign off and the cash Divi found. Every number links to its source row.

This public demo replays a recorded real run of Meta's Muse models, so it is the same every time. All company data is fictional.
